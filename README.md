# LCN çevresindeki liseler

MIM 401D · G1 · Linificio Canapificio Nazionale (Fara Gera d'Adda)

Etkileşimli harita, üç katman:
- **Liseler:** uzmanlık filtresi, okul künyesi, okul çıkışından sonra toplu taşımayla fabrika parseline varış.
- **Bisiklet rotaları** (`#bisiklet`): Fara ve Adda çevresindeki tanımlı rotalar, bölgesel etkinlikler ve gruplar.
- **Topluluklar** (`#topluluklar`): fabrikanın güneyindeki tarihî merkezde dernek merkezleri ve topluluk mekânları, kategori filtresiyle.

Kaynaklar: Fara Gera d'Adda Belediyesi duyuruları, AGEA 2018 ortofoto (Regione Lombardia), piste-ciclabili.com rota izleri, AGEA 2012 ortofoto (Portale Cartografico Nazionale), OpenStreetMap katkıcıları, OSRM, SAI Autolinee T10 tarifesi (14.09.2026).
